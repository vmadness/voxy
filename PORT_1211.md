# Voxy port: dev (MC 26.2) → MC 1.21.1 + Sodium 0.8

Branch: `mc_1211`. Reference: `ref_m3t4f1v3/voxy` branch `mc_1211` (fetched as git remote `ref_m3t4f1v3`) — older voxy code ported to 1.21.1 with Sodium 0.6.13; useful for 1.21.1-era shims (fog, mixin plugin, compat), NOT for sodium API (we target Sodium `mc1.21.1-0.8.12-fabric`, whose API is closer to the 0.9.x dev already uses).

## Baseline facts

- Dev targets: MC 26.2, Sodium 0.9.1, Java 25, fabric-api 0.152.2, loom 1.16, new blaze3d GPU abstraction (`GpuDevice`, `RenderPass`, `GpuBuffer`, `pipeline.RenderPipeline`), `net.minecraft.resources.Identifier`, new fog (`client.renderer.fog.FogRenderer`/`FogData`), `LevelExtractor`, `DebugScreenEntryList`.
- Target: MC 1.21.1 (mojmap: `ResourceLocation`, pre-GpuDevice blaze3d, old fog, no LevelExtractor), Java 21, Sodium `mc1.21.1-0.8.12-fabric` (confirmed on Modrinth, released 2026-07-06), fabric-api `0.116.6+1.21.1`, loom `1.11-SNAPSHOT`+, loader `>=0.17.2`.
- Version-dependent surface: ~55 files import `net.minecraft.*`, 22 files use Sodium API, 12 files touch `com.mojang.blaze3d`, 13 MC mixins + 9 Sodium mixins + 10 Iris mixins, access widener, fabric.mod.json.
- Voxy has its own raw-GL layer (`client/core/gl/`, LWJGL GL45 DSA) — version-independent, keep as-is.
- Reference branch divergence: merge-base `41dd201d`, dev is 99 commits ahead, ref is 33 ahead; 145 files differ in src.

## Decisions

- Orchestration: Fable 5 orchestrates/reviews only; code written by gpt-5.6-terra / Sonnet 5 (mechanical/normal) and gpt-5.6-sol (complex), via Codex plugin and Agent tool.
- Keep dev's `findSodiumVersion()` build logic, point it at `mc1.21.1-0.8.12-fabric` via modrinth maven.
- Iris/Nvidium/Vivecraft/Flashback/Chunky: defer, gate mixins on mod presence (ref branch has a `ClientVoxyMixinPlugin` doing exactly this — reuse the approach).
- Sodium fog: dev consumes sodium `FogParameters` in 6 files — verify what sodium 0.8.12 exposes on 1.21.1 before deciding shim vs direct use.
